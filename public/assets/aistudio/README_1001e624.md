# Auction Room — IPL Auction Instrument

**Auction Room** is a zero-dependency, local IPL auction system engineered for live in-room auction events. It provides an event-sourced rules engine, real-time multi-client synchronization over Server-Sent Events (SSE), an Operator Console for the auctioneer, and an Arena Display for 1080p / 4K projectors.

---

## 1. Quick Start (One Command)

### Windows
Double-click `start.bat` or run in PowerShell / Command Prompt:
```cmd
start.bat
```

### macOS & Linux
Make executable and run:
```bash
chmod +x start.sh
./start.sh
```

### Using npm
```bash
# Mega Auction (Default: 120 Cr purse per franchise, empty squads)
npm start

# Mini Auction (Custom retained squads & adjusted purses)
npm run start:mini
```

The server binds to port `3000` on all network interfaces (`0.0.0.0`) and automatically opens your browser:
* **Operator Console (Auctioneer / Host)**: [http://localhost:3000/operator](http://localhost:3000/operator)
* **Arena Display (Projector / Audience)**: [http://localhost:3000/arena](http://localhost:3000/arena)
* **Projector from Another Laptop / Screen**: `http://<YOUR-LAPTOP-IP>:3000/arena` (the exact IP is displayed in the terminal upon startup)

## 2. Key Features & Views

### Operator Console (`/operator`)
* **Stage Tab**: Live bidding card, price numeral in Indian Cr/Lakh notation, 10 franchise paddles with real-time eligibility guards, bid trail chips, custom jump bids, and call-by-name search.
* **Squads Tab**: Complete rosters for all 10 franchises with overseas markers, purchase price, role filters, and player release with modal confirmation.
* **Team Stats Tab**: Real-time financial ledger tracking purse spent, remaining purse, squad count, overseas count, and one-click **Export CSV**.
* **Activity Log & Unsold Queue**: Live chronological trail and single-click **Accelerated Round** trigger.
* **Offline Detection**: Live connection dot in header turns green when connected; warns immediately if network or server drops, and recovers automatically on reconnect.

### Arena Display (`/arena`)
* Designed strictly for projectors (1366x768 to 3840x2160 4K).
* **Idle State**: Displays next upcoming player on the floor and auction progress metrics.
* **Live Bidding**: 144px price numeral in marigold gold, full player card with ratings and base price, and real-time leading franchise banner.
* **Sold Overlay**: High-impact 4-second choreographed reveal celebrating the winning franchise and final price.
* **Unsold Overlay**: Clean madder badge indicating player passed to the accelerated round.

## 3. Operator Hotkeys Reference

| Key | Action | Details |
|---|---|---|
| `1` – `9` | Bid for Franchise 1–9 | KKR (1), CSK (2), SRH (3), LSG (4), DC (5), RCB (6), RR (7), GT (8), PBKS (9) |
| `0` | Bid for Franchise 10 | Mumbai Indians (0) |
| `N` | Next Lot | Calls the next pending player from the catalog onto the floor |
| `S` | Sold | Sells the lot to the current highest bidder; triggers Arena overlay |
| `U` | Unsold | Marks player as unsold (only enabled when no bids placed) |
| `C` | Custom Bid | Arms custom bid input; type amount in Cr (e.g. `2.5`), press `Enter`, then press team key |
| `Ctrl + Z` / `Cmd + Z` | Undo | Reverses last action (bids, sold, unsold, release) without purse drift |
| `Esc` | Cancel | Closes search dropdown, release modal, or cancels custom bid |

> **Note**: Held keys are suppressed (`e.repeat` guard) to prevent accidental double-bidding.

## 4. Operator PIN Security

To protect the Operator Console from unauthorized bidding over shared Wi-Fi:

1. Launch the server with the `PIN` environment variable:
   ```cmd
   set PIN=auction2026&& npm start
   ```
   Or in Linux / macOS:
   ```bash
   PIN=auction2026 npm start
   ```
2. When PIN is active, commands sent without the PIN receive `401 Unauthorized`.
3. In the Operator Console header, click the **PIN** button, enter `auction2026`, and click Save. The PIN is securely remembered in your browser session (`localStorage`).

## 5. Persistence, Backups & Reset

### How Persistence Works
* Every command (bid, sold, unsold, release, undo) is appended atomically to `data/events.json`.
* If the laptop crashes or loses power, simply restart `start.bat`. The event log is replayed from event 1 to restore the exact state, lot, leader, and team purses.
* A rolling backup worker saves snapshots to `data/backups/events-<timestamp>.json` every 60 seconds (keeping the last 30 snapshots).

### How to Reset for a Fresh Auction
To wipe previous bids and start a brand new auction:
1. Stop the server (`Ctrl + C` in the terminal).
2. Move or delete the `data` directory:
   ```cmd
   ren data data-archive
   ```
3. Restart `start.bat`. A clean auction state will initialize automatically.

## 6. Adding Player Photos

The catalog contains 180 players with zero external dependencies. By default, every player renders an initials monogram card.

To supply official player photos:
1. Place PNG, JPG, or WEBP images inside `public/assets/players/deck_N/`.
   * Example: `public/assets/players/deck_1/sachin_tendulkar.png`
2. Match the exact filename specified in `seed/players.csv` (`photo_path` column).
3. The server checks file presence at boot; if a photo exists on disk, it is served immediately. If missing, it falls back to the designed monogram with no broken image icons.

## 7. Pre-Event Organizer Checklist

Complete this checklist 30 minutes before the auction begins:

- [ ] **Power & Sleep Settings**: Ensure both the Host laptop and the Projector laptop have screen saver, display sleep, and system sleep set to **Never**.
- [ ] **Projector Native Resolution**: Connect HDMI/DisplayPort to the projector, set display mode to "Extend", open Chrome/Edge on the projector screen at [http://localhost:3000/arena](http://localhost:3000/arena), and press `F11` for borderless fullscreen.
- [ ] **Close Background Apps**: Close Windows Update, anti-virus scans, cloud sync clients (OneDrive, Dropbox), and heavy browser tabs to prevent background lag.
- [ ] **Test Network Sync**: Open [http://localhost:3000/operator](http://localhost:3000/operator) on the host screen. Confirm the green connection dot is visible. Tap hotkey `N` to open a test lot, place a test bid with `1`, verify the projector reflects the bid instantly (< 500ms), and hit `Ctrl + Z` to undo.
- [ ] **Test CSV Export**: Click the **Stats** tab in Operator Console, click **Export CSV**, and verify that `auction-results.csv` downloads cleanly and opens in Microsoft Excel.
- [ ] **Audio / Chime**: If using sound effects, test speaker levels before attendees arrive.
