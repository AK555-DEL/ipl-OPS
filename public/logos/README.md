# Club Franchise Logo Storage (`delhi_captails.png`)

Place or replace your custom **Daily Captains / Delhi Capitals** PNG logo file right here at:

```
public/logos/delhi_captails.png
```

### Details
- **Exact Filename**: `delhi_captails.png` (PNG format)
- **Served URL**: `/logos/delhi_captails.png`
- **Where It Appears**:
  1. **Team Members / Franchise Slot**: Displayed on the Delhi Capitals (`DC` / `IPL-T03`) franchise crest across the Arena Team–Players Dashboard (`/arena`), Bidder Console (`/bid`), Live Stage, Operator Squads, and Team Stats.
  2. **Players**: Displayed on the Delhi Capitals Franchise Title card (`IPL-T03`) AND alongside every player drafted/signed by Delhi Capitals (`DC`) across Arena player rows, Bidder signed player lists, Operator Squads rows, and `PlayerPortrait`.
- **Upload via UI**: You can also upload a new `.png` directly from `/deploy` -> **Daily Captains Logo (`delhi_captails.png`)**, which overwrites `public/logos/delhi_captails.png` in place.
